# AI チャット

サーバー内で bot、または bot の管理ロール（bot の参加時に Discord が作る同名のロール）を本文中に直接メンションすると、その投稿のテキストを設定した OpenAI 互換チャット補完 API に送り、元投稿に返信する。`AI_CHAT_API_KEY` が未設定なら無効。既定の URL・モデルはさくらの AI Engine 向けで、他の互換 API へ変更できる。DM、bot・Webhook の投稿、編集、返信時の通知だけで本文にメンションのない投稿には反応しない。既存の prefix コマンドは優先する。

## 外部に送る情報

bot と管理ロールのメンショントークンを取り除いた**投稿本文のみ**を送る。本文中の別のユーザー・ロール・チャンネルへのメンションはそのまま送る。チャンネル履歴、返信先、作者情報、添付、埋め込み、sticker は取得・送信しない。会話履歴や質問・回答は DB に保存せず、ログにも本文やトークンを残さない。秘密情報は投稿しないこと。

空の質問と 2000 文字を超える質問は API に送らず案内する。回答は 1900 文字を超えたら末尾を省略し、本文中のメンションと返信先への通知を抑止する。

同一ユーザーの処理中の再投稿と、bot 全体で同時 2 件を超える呼び出しは断る。API 呼び出しはタイムアウトを設け、失敗・レート制限時は取得失敗を案内して再試行しない。1 人あたり月 30 回まで利用でき、月の区切りは `TIMEZONE` の月初。上限到達後の投稿には API を呼ばず案内を返し、失敗した呼び出しは回数に数えない。この 30 回は bot 側の上限で、サービス側の無償枠を保証するものではない。契約プランと利用枠も確認する。

Discord は bot をメンションした投稿の本文を Message Content Intent なしで渡すため、この機能のために同 intent は有効にしない。管理ロールを受け付けるのは、`@ctfbot` の補完候補にユーザーとロールが並び、ロールを選ぶ誤りが起きやすいためだ。ロールへのメンションは intent 免除の対象と保証されないので、intent が無効な構成（TTS 無効時）では本文が空で届き、反応しないことがある。実際のサーバーでの確認は運用者が行う。[Discord の説明](https://docs.discord.com/developers/gateway/you-might-not-need-a-privileged-intent) を参照。
