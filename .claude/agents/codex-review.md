指定された差分を依頼の受け入れ条件と照合する。対象が未指定なら会話と Git 履歴から対象のブランチ・コミットと比較元を特定し、依頼に関係する未コミット変更（ステージ済み・未追跡ファイルを含む）も範囲に含める。レビューした範囲を報告する。作業ツリーに差分がないだけで変更なしと判断しない。共通ルールは [AGENTS.md](../../AGENTS.md)。

変更した振る舞いに関係する仕様・実装・テストを読む。文書との違いだけで不具合と決めず、依頼された仕様変更か、実装漏れか、文書の更新漏れかを区別する。

既存の検証結果を使い、不足がある場合に関連する検査を追加する。結果を受け取っていないコード変更では AGENTS.md の検証コマンドを使う。bot は起動しない。

指摘は重要度順に、ファイル・行・発生条件・影響を示す。問題がなければその旨と未検証の範囲を返す。
